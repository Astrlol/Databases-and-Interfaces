# tietokannat_2026
Oamkin Tietokannat ja rajapinnat -kurssin (Databases and Interfaces) viikkotehtävät.

Jokaisen viikon tehtävät ovat omassa kansiossaan. Tehtävät on tehty MySQL:llä (UniServerZ), ja tiedostoissa näkyvät sekä kyselyt että niiden tulokset.

Käytetyt tietokannat: oma lemmikkitietokanta (pet ja owner), employees ja sakila.
